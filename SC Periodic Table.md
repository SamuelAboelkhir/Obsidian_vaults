# Intro
- The periodic table is the most useful tool to a chemist
- You get to use it on every test
- It organizes lots of information about all the known elements
![[ColorLargeTypePeriodicTable.png]]
# History of the table
## Dimitri Mendeleev: Father of the Table
- He's the first man to create a periodic table
- In his table he:
	- Put elements in rows by increasing atomic weight
	- Put elements in columns by the way they reacted
- He has an element named after him **Mendelevium (Md)**
## Problems with his design
- He left blank spaces for possibly undiscovered elements, and he turned out to be correct
- He broke his pattern of increasing atomic weight to keep similar reacting elements together
## Meneleev and Meyer
- In 1869 Mendeleev and Meyer published a nearly identical classification scheme for elements discovered to date
## Henri Moseley
- He established that each element has a unique atomic number, which became the new basis of how the periodic table is organized
	- Elements are added to rows by increasing atomic number, not atomic weight
## The current day periodic table
- This table has
	- 7 rows called periods
	- 18 columns called groups
	- Is ordered by increasing atomic number
- There is a repetition observed in the physical and chemical properties of the elements that was observed after they were ordered by atomic number. This pattern is called **The Modern Periodic Law**
# Groups
- Elements in the same group have similar chemical and physical properties
- This is something that Mendeleev did on purpose in his table, but manifested naturally in the modern table (**The Modern Periodic Law**)
- The reason behind it is that elements of the same group have the same number of **valence electrons**
